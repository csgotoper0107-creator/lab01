# Лабораторная работа 2

## Тема
Разделение приложения на frontend- и backend-сервисы с использованием APIFlask и Flask

## Описание
Проект состоит из двух независимых сервисов:
- **backend** — предоставляет API и документацию OpenAPI
- **frontend** — обращается к backend и отображает полученные данные

## Запуск
1. Запустить backend: `python backend/app.py`
2. Запустить frontend: `python frontend/app.py`
3. Открыть http://localhost:5000
